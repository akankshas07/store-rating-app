# Store Rating App

A full-stack web application for managing stores and allowing users to rate stores.

## Tech Stack

### Frontend
- React.js
- JavaScript
- CSS

### Backend
- Node.js
- Express.js
- REST APIs

### Database
- PostgreSQL

## Features

- User registration and login
- Role-based access control
- Store management
- Store rating functionality
- Admin functionality
- REST API integration
- PostgreSQL database integration
